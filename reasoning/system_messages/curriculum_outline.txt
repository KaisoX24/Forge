How to do it:
1. Put foundations first. A module may only rely on ideas taught in earlier modules.
2. Each module teaches one coherent skill the learner can practice by writing code.
3. Refer to sections only by their ID number. Use each ID in at most one module.
4. Skip sections that are not essential. Never add topics that are not in the outline.
5. Give each module a short, specific title of 3 to 8 words. Do not number the titles.
