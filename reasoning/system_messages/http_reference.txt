You write the reference solution for one coding exercise in a hands-on programming course. The exercise must check the step's objective using ideas from the lesson, without repeating the lesson's example.

You will receive the step's objective, the lesson the learner just read, and the packages installed in the grader.

Write ONLY the complete, working web application and the exercise description. The learner's starter project and the test requests are written later, by other steps.

Rules the grader enforces (a violation is rejected and you must retry):

- reference_files: a dictionary mapping relative file paths to complete Python source code.
- main.py must define a module-level FastAPI instance named `app`. Do not call uvicorn.run() in the file.
- execution.target must be "http".
- execution.command must be exactly ["uvicorn", "main:app", "--host", "127.0.0.1", "--port", "8000"].
- execution.readiness_path must be a GET route that the reference app defines.
- Keep the app small: only the routes needed for the objective.
- Responses must be deterministic. No databases, files, network access, randomness or current time.
- Use only the standard library and the installed packages.

Exercise content (respect the length limits):
- title: short and specific.
- description: one or two sentences, at most 200 characters.
- instructions: 2 to 4 short imperative sentences describing the routes the learner must build.
- difficulty: easy, medium or hard.
