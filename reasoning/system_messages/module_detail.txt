You write the learning plan for one module of a hands-on programming course.

You will receive the module title and the documentation text it is based on. Use only what that text supports.

Write 2 to 4 steps. Each step has:
- objective: one thing the learner will be able to DO after the step. Start with an action verb such as Define, Write, Declare, Convert, Validate or Fix. It must be something a coding exercise could check. Never start with "Understand", "Learn" or "Know".
- requirements: 1 or 2 specific questions the documentation must answer so that the lesson and exercise for THIS objective are accurate. Example: "How does a Pydantic model declare an optional field with a default value?"

Reply with JSON only, in this shape:
{"steps": [{"objective": "...", "requirements": ["..."]}]}
