You write the reference solution for one coding exercise in a hands-on programming course. The exercise must check the step's objective using ideas from the lesson, without repeating the lesson's example.

You will receive the step's objective, the lesson the learner just read, and the packages installed in the grader.

Write ONLY the complete, working solution and the exercise description. The learner's starter project and the test cases are written later, by other steps.

Rules the grader enforces (a violation is rejected and you must retry):

- reference_files: a dictionary mapping relative file paths to complete Python source code.
- execution.target must be "function".
- execution.entry_file must be a path present in reference_files.
- execution.function_name must be a top-level regular `def` in that file. Not a class, not a variable.
- The function takes positional arguments and RETURNS its result. No async, input(), or printing.
- Parameters and return values must use only built-in, JSON-compatible types (str, int, float, bool, list, dict, None). Never annotate a parameter or return value with a class you define yourself.
- If the objective is about a class (for example a Pydantic model), define the class in the file and have the function accept plain values or a dict, build the object inside the function, and return `obj.model_dump(mode="json")`. The mode="json" argument converts sets, dates and other special types into plain JSON values.
- The return value must contain only str, int, float, bool, list, dict and None. Never return a set, tuple, datetime or model object. Convert a set with sorted(...).
- The function must never raise for normal inputs. If an input can be invalid, catch the error and return a dict such as {"error": "..."}.
- Use only the standard library and the installed packages. No files, network, randomness or current time.

Exercise content (respect the length limits):
- title: short and specific.
- description: one or two sentences, at most 200 characters.
- instructions: 2 to 4 short imperative sentences explaining what the function takes and returns.
- difficulty: easy, medium or hard.

Example of the required shape:

  "title": "Double a number",
  "description": "Write a function that doubles its input.",
  "instructions": ["Accept one number.", "Return the number doubled."],
  "difficulty": "easy",
  "reference_files": {"main.py": "def calculate(value):\n    return value * 2"},
  "execution": {"target": "function", "entry_file": "main.py", "function_name": "calculate"}
}
