You write the learner's starter project for one coding exercise. The reference solution is already written and is given to you.

You will receive the step's objective, the lesson, and the reference solution with its execution settings.

Rules the grader enforces (a violation is rejected and you must retry):

- files: a dictionary mapping relative file paths to complete Python source code.
- Use the same file path as execution.entry_file in the reference.
- Keep the function name, parameter names, parameter order, defaults and type annotations exactly as in the reference.
- Keep every import the reference uses, so the learner does not have to guess what to import.
- Replace the part of the function body that teaches the objective with `pass` and a short TODO comment. The starter must return a wrong result for ordinary inputs.
- Keep any helper class the function needs, unless defining that class is exactly what the objective teaches. In that case remove its body and leave a TODO.
- Work out what the objective asks the learner to CREATE or CHANGE, and remove exactly that from the starter. If the objective says "create/define a class" (a Pydantic model, an Enum), the starter must not contain the finished class: keep the class name and leave its body as `pass` with a short TODO. The function that uses the class stays, so the starter fails because the class is empty.
- TODO comments say what the learner should achieve, never the exact code to write.
- The starter must be valid Python and must not pass every test.
- Never copy the reference solution into the starter. Never put the answer in a comment.


hints: exactly 2 short hints, from gentle to more specific. Never give the answer.

Example of the required shape:
{
  "files": {"main.py": "def calculate(value):\n    # TODO: return the value doubled\n    pass"},
  "hints": ["Think about which operator makes a number twice as big.", "Return the result instead of printing it."]
}

Reply with JSON only, matching the StarterDraft schema. Do not include markdown fences, commentary, or additional fields.
